## 3. 손님이 궁금한 것 (연락하기 전에)
1. 진행 방식: 어떻게 진행되나 (카톡 오픈채팅에서 강의 링크 받기 → 네이버 카페에 결과물 올리기)
2. 초보 가능 여부: AI를 하나도 몰라도 따라갈 수 있나
3. 얻는 것: 100일이 끝나면 무엇을 얻나 (결과물·실력) — 아래 '100일 뒤 얻는 것' 참고

### 100일 뒤 얻는 것 (클로드가 정리한 안 — 사용자 확인 후 확정)
- **매일 10분 AI로 콘텐츠를 만드는 습관** — 혼자서는 며칠 만에 멈추던 일을 100일 동안 이어 가요.
- **네이버 카페에 차곡차곡 쌓인 내 결과물 모음** — 100일 동안 올린 글·그림·영상이 그대로 내 포트폴리오가 돼요.
- **"AI가 처음"에서 "AI로 직접 만들 수 있는 나"로** — 직장 업무, 내 가게·서비스 홍보, 수업 자료에 바로 써먹을 수 있어요.
- **함께 하는 동료** — 오픈채팅과 카페에서 같은 길을 걷는 사람들과 서로 보고 배워요.
- 주의: 개수·성과 숫자(예: "콘텐츠 100개 완성")는 실제 운영과 맞는지 확인되기 전까지 쓰지 않는다.
